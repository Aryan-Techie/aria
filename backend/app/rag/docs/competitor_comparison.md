# Apple vs. a typical Windows PC fleet

Prospects almost always open with "isn't this more expensive than what we have now?" — here's the honest comparison, not a sales dodge.

## Upfront price
- A typical business Windows laptop: $700-$1,200 depending on spec.
- MacBook Air (M3): starts at $999, with volume pricing from $949 at 20+ devices.
- Sticker price is close to parity at the low end; Apple is genuinely more expensive at the premium end (MacBook Pro vs. a comparable Windows workstation).

## Total cost of ownership (this is where Apple actually wins)
- IT support tickets: Mac fleets typically generate significantly fewer help-desk tickets than Windows fleets of the same size — fewer driver conflicts, less malware remediation, fewer forced reimages.
- Device lifespan: Mac hardware commonly stays in productive service 1-2 years longer than an equivalent Windows laptop before replacement.
- Resale/trade-in value: Mac and iPhone hold resale value substantially better than most Windows/Android equivalents, which lowers effective 3-year cost when trade-in credit is factored in.

## Switching cost — the real objection
- Data migration: Apple provides centralized, IT-run migration tooling for Windows-to-Mac transitions — this is not a manual, device-by-device process.
- Employee training: most employees already use iPhone/iPad personally, which shortens the learning curve versus what IT typically expects.
- Software compatibility: the major productivity suites (Microsoft 365, Google Workspace, Slack, Zoom, Adobe Creative Cloud) run natively on Mac — this is not an emulation/compatibility-layer situation.

## Security
- Malware targeting Mac fleets is dramatically less common in practice than malware targeting Windows fleets, which is real, but IT should still deploy standard MDM policies (Apple Business Manager works with Jamf, Kandji, and Intune) rather than treating this as "no security work needed."

## When a prospect says "our current PCs still work fine"
Don't argue against it — ask what's actually driving them to consider a change (a lease renewal, security incident, employee requests, a new hire cohort). If there's no real trigger yet, that's a legitimate "not ready" signal, not an objection to push past.
